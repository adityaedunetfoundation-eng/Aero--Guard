AeroGuard Project Presentation - Simple 5-Minute Script

Good morning everyone.

Today I am going to present our project, AeroGuard.

AeroGuard is an AI-based airport safety and obstacle detection system. It is designed to monitor airport runways, ramps, cargo areas, and other restricted places.

The main problem we are trying to solve is Foreign Object Debris, also called FOD. FOD means any unwanted object present in an airport area. It can be a bag, a vehicle, a person, a suitcase, a piece of equipment, or any other object. These objects can create serious safety problems, especially near aircraft.

Our idea is to use a camera and artificial intelligence to continuously monitor the area. The system detects objects in the video and gives navigation guidance to a simulated autonomous rover.

Now I will explain how our system works.

First, the operator opens the AeroGuard dashboard. The operator can upload a patrol video, upload an image, or select a live camera. The video is shown on the dashboard.

The system takes the video one frame at a time and sends each frame to the backend. The backend uses the YOLOv8 computer vision model to analyse the frame. YOLO means You Only Look Once. It is a real-time object detection model.

When YOLO detects an object, it draws a box around that object. The box follows the real position of the object in the video. The system also shows the name of the object and the confidence score. For example, it can detect a person, car, truck, airplane, backpack, or suitcase.

[Show the uploaded video and detection box here.]

The most important feature of our project is automatic navigation guidance. The system checks where the obstacle is located in the frame.

If there is no obstacle in the path, the system displays FORWARD and gives the voice alert, “Path clear. Moving forward.”

If an obstacle is detected on the left side, the system displays TURN RIGHT because the rover should move away from that obstacle.

If an obstacle is detected on the right side, the system displays TURN LEFT.

If a large obstacle is detected in the centre and it is very close, the system displays BRAKE and gives the voice alert, “Warning. Emergency braking engaged.”

[Show the FORWARD, TURN LEFT, TURN RIGHT, and BRAKE indicators here.]

These navigation decisions are visible on the live dashboard. The dashboard shows the current mission status, detection confidence, navigation action, current trajectory, radar display, system health, and activity log. The navigation action also has a small animation so the operator can easily understand the current decision.

The system provides automatic browser voice alerts. The operator does not need to give a voice command for every movement. The system itself announces the navigation decision after analysing the video. Manual commands can also be added in the future for operator control.

For this project, we used Python and Flask for the backend. We used Ultralytics YOLOv8 for object detection, OpenCV for handling images and videos, and NumPy for processing image data. The frontend was developed using HTML, CSS, and JavaScript. The application can run locally and can also be deployed online using Render.

The system has several advantages. It can monitor video in real time, detect multiple objects, show the exact object position, provide navigation guidance, and give voice alerts. It also provides a clear dashboard for the operator. Since it is software-based, it can be developed at a lower cost before connecting it to real hardware.

At present, AeroGuard is a prototype and simulation. It shows the detection and navigation decision on the screen, but it does not directly move a real rover. In the future, we can connect it to a microcontroller, motor driver, camera, GPS module, and other sensors. Then the navigation commands can be sent to a physical rover.

The future scope of AeroGuard is very broad.

First, we can connect the software to a real rover using a microcontroller, motor driver, and battery system. Then the commands generated by the system, such as forward, left, right, and brake, can control the actual motors.

Second, we can add more hardware sensors, such as ultrasonic sensors, LiDAR, GPS, and distance sensors. These sensors can provide extra information and help the system work more reliably in different weather and lighting conditions.

Third, we can improve the AI model by training it with airport-specific images. This can help the system detect small runway objects more accurately and reduce false detections. We can also add object tracking so the system can follow the same object across multiple video frames.

Another future feature is a complete control room dashboard. It could store mission history, show a live map, send alerts to security staff, and allow operators to monitor multiple rovers from one place. The system could also save detection images and generate automatic safety reports.

We can also add night vision, thermal cameras, automatic charging, obstacle-distance estimation, and route planning. With these improvements, the rover could choose a safer route instead of only turning left or right.

Finally, the system must be tested in controlled airport-like environments and later validated according to proper safety and aviation requirements. Before real-world use, it would need hardware testing, safety testing, human supervision, and certification.

To conclude, AeroGuard is an AI-powered FOD detection and obstacle avoidance prototype. It monitors the video, detects objects using YOLOv8, shows their exact position, and automatically suggests forward movement, turning, or braking. It also gives voice alerts to help the operator understand the system quickly.

Our aim is to use this technology in the future to improve airport safety and reduce the risk caused by foreign objects.

This was our project, AeroGuard. Thank you.
